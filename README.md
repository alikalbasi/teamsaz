# تیم‌ساز (TeamSaz)

تیم‌ساز پروژه‌ای دانشگاهی برای طراحی یک پلتفرم پیدا کردن هم‌تیمی، تشکیل تیم و همکاری روی پروژه‌هاست. بسیاری از صاحبان ایده برای شروع یا تکمیل پروژه به افرادی با مهارت‌های مکمل نیاز دارند. از سوی دیگر، دانشجویان و افراد متخصص به دنبال پروژه‌ای هستند که بتوانند در آن تجربه عملی کسب کنند. هدف تیم‌ساز ایجاد مسیری برای معرفی پروژه‌ها، مشخص کردن نقش‌های موردنیاز و پیدا کردن افراد مناسب است.

مخاطبان پروژه دانشجویان، برنامه‌نویسان، طراحان، تولیدکنندگان محتوا، صاحبان ایده و بنیان‌گذاران تیم‌های نوپا هستند. دانشگاه‌ها و برگزارکنندگان رویداد نیز از مخاطبان احتمالی فازهای بعدی‌اند.

## امکانات موجود

- **تیم ما** — معرفی علی کلباسی، بنیان‌گذار و تنها عضو فعلی، همراه با تصویر، مهارت‌ها، هدف و ارزش‌های تیم‌ساز. این صفحه هدر و منوی مشترک سایت را دارد.
- **تماس با ما، ورود و ثبت‌نام** — رابط‌های فارسی و راست‌به‌چپ با کنترل‌های فرم HTML و استایل مشترک واکنش‌گرا.
- **پوسته فرم‌ها** — متغیرهای رنگ Material Design 3 با رنگ اصلی `#006B5E` و پشتیبانی از طرح روشن و تاریک بر اساس تنظیم سیستم.

فرم‌ها رابط کاربری ایستا هستند. ارسال واقعی پیام، ایجاد حساب، احراز هویت و ذخیره اطلاعات پیاده‌سازی نشده‌اند.

## اجرای محلی

فایل `team.html` یا یکی از سه صفحه فرم را مستقیماً در مرورگر باز کنید. برای اجرا روی HTTP، اگر Python 3 نصب است، از ریشه پروژه این دستور را اجرا کنید.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

سپس در مرورگر به `http://127.0.0.1:8000/team.html` بروید یا نام فایل را با `contact.html`، `login.html` یا `register.html` جایگزین کنید.

## نقشه راه

1. طراحی صفحه اصلی، فهرست پروژه‌ها با جست‌وجو و فیلتر، جزئیات پروژه، معرفی تیم‌ها، پروفایل مهارت‌ها، فرم تعریف پروژه و داشبورد.
2. افزودن بک‌اند PHP/Laravel و پایگاه داده برای حساب کاربری، احراز هویت، نقش‌ها و سطح دسترسی، ثبت پروژه و مدیریت درخواست‌های عضویت.
3. توسعه ابزارهای همکاری مانند مدیریت کارها، اعلان‌ها و گفت‌وگو، همراه با API و پنل مدیریت.
